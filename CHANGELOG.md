# Changelog

## V1.2.0
- Categories with emoji that you create, rename, reorder and delete (starter set included)
- Library search, category filters, sorting, and a Featured shelf
- Edit everything about a library app: name, category, developer, description, notes, featured, custom icon
- "Add details" screen right after uploading an app
- Update IPA: swap in a new version while keeping all its details
- Default sign settings per app (JIT, more RAM, 120Hz, options…) so people just tap Sign
- Simple signing screen with the extra options tucked under "More options"
- Bulk select: move, show, hide, feature or delete many apps at once
- Resumable uploads for big files, with speed and time left, and the screen kept awake
- Import links: Dropbox links fixed automatically, clear error for web-page links
- Certificates show what the profile allows (JIT, More RAM, Extended VA) and can be renamed
- Signed tab: days left per app, and old signed files auto-deleted to save space (setting)
- Storage breakdown with cleanup buttons in Settings

## V1.1.0
- App Library: apps the owner uploads can be signed and installed by invited users; hide/show apps and add descriptions
- Accounts: invite codes, username + password, and sign in with iPhone (UDID profile)
- Each user has their own certificates and signed apps (newest 10 kept by default)
- Certificates show whether your iPhone is in the profile
- Entitlements: JIT support, increased memory limit, extended virtual addressing, custom entitlements, with profile warnings
- Info.plist editor: 120Hz ProMotion, Game Mode, full screen, custom keys
- Owner Users tab: manage people and invites
- Signing queue so multiple people can sign at once
- Cleaner signing engine version in Settings

## V1.0.0
- First release: library, certificates, signing options, tweak injection, one-tap install
